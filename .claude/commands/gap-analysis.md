Run a gap analysis between a job description and the candidate profile.

Steps:
1. Read personal/candidate.md for candidate background, metrics, and experience
2. Ask the user to paste the full job description
3. Decompose the JD:
   - Extract explicit requirements
   - Extract qualifications and tools
   - Extract soft skills and culture signals
   - Infer hidden business needs (what they really need vs what they wrote)
4. For each requirement rate the candidate fit:
   - Strong: candidate owns this clearly and can defend it in an interview
   - Partial: honest adjacent experience, requires reframing, defensible
   - Gap: candidate does not have this, do not claim it
5. Present alignment table with honest ratings
6. Identify the 3 strongest selling points for this specific role
7. Identify the 1-2 gaps most likely to come up in screening
8. Give an honest recommendation:
   - Strong fit: apply with confidence, standard tailoring
   - Reasonable fit: apply honestly, flag reframes needed
   - Stretch: apply if desired but flag significant gaps, do not misrepresent
9. Recommend which competency table variant to use based on the audience pools defined in candidate.md
10. Recommend bullet reordering priority for this JD

Hard rule: Never recommend claiming experience the candidate does not have. Honesty is non-negotiable.
